# Mini Pocket Status UI selection

These navigation assets were selected from the user-supplied archive
`Super Asset Bundle #5 Mini Pocket Status 2.1.zip`.

Only the files needed by Little RPG are copied here; the original Aseprite
sources and the rest of the bundle are not redistributed. The supplied
archive did not include a licence file, so the project owner must retain the
purchase/licence record before distributing a commercial build.
